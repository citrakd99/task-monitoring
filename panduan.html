1. Mulai: masuk & pasang aplikasi

  1. Buka aplikasinya, pilih Nama Anda, ketik PIN, lalu tekan Masuk. Nama dan PIN dibuat oleh admin.
  2. Sesi login berlaku 12 jam. Setelah itu aplikasi meminta PIN lagi.
  3. Salah PIN 5 kali akan mengunci login selama 15 menit.

Pasang sebagai aplikasi

  • HP Android (Chrome): ketuk ⋮ → Tambahkan ke layar utama / Instal aplikasi.
  • iPhone / iPad (Safari): ketuk tombol Bagikan → Tambahkan ke Layar Utama.
  • Laptop (Chrome / Edge): klik ikon pasang di ujung kanan kolom alamat, atau tombol ⤓ Pasang di kanan atas aplikasi.

Setelah terpasang, aplikasi punya ikon sendiri dan tetap bisa dibuka saat sinyal hilang (hanya baca).

Di mode Pribadi, bilah atas berubah hijau dan bertuliskan “· Pribadi” supaya tidak tertukar. Task yang dibuat mengikuti mode yang sedang aktif, dan tidak bisa dipindah ke mode lain.

Di mode Tim, kartu milik orang lain bertanda 🔒 lihat saja: Anda bisa membukanya tetapi tidak bisa mengubahnya.

4. Kanban Plan Task

Untuk memantau pekerjaan. Isi tiap kartu: Pekerjaan, PIC, Plan Start – Plan Finish, prioritas, dan catatan.

Plan Task → Plan Task Ready → Plan Task Closed
dari Plan / Ready bisa ke Plan Task With Note

  1. Buka tab Plan Task, tekan +, isi pekerjaan, PIC, dan tanggal, lalu Simpan. Kartu masuk ke kolom Plan Task.
  2. Untuk memindahkan: buka kartu lalu tekan tombol status tujuan. Di laptop, kartu bisa diseret ke kolom lain.
  3. Plan Task With Note dipakai bila ada kendala/keterangan. Catatan wajib diisi, dan tampil langsung di kartu.
  4. Dari Plan Task Closed, kartu bisa di-Reopen kembali ke Plan Task.

5. Kanban Dokumen

Untuk tracking dokumen.

Open → Progress → Submit → Closed
Submit bisa ke Revisi (lalu kembali ke Progress) atau Reject

  • Tambah lewat + di tab Dokumen. Pindah status sama seperti Plan Task.
  • Kolom “Catatan perubahan” di detail bersifat opsional, misalnya alasan revisi atau reject.
  • Centang Tampilkan Plan Task With Note untuk memunculkan plan task ber-catatan sebagai kolom tambahan di kiri. Kolom itu hanya untuk dilihat dan dibuka.
  • Task yang sudah Closed/Reject tidak bisa diedit; Reopen dulu.

6. Prioritas & overdue

  • Pilih Urgent, High Priority, atau Normal di form task.
  • Urgent dan High diberi tanda ⚑ dan otomatis naik ke atas kolom.
  • Task yang melewati tanggal selesai dan belum closed ditandai merah OVERDUE.
  • Dropdown Semua prioritas di baris filter berlaku di semua tab.

7. Kalender

  • Tiap task tampil sebagai garis berwarna dari tanggal mulai sampai selesai; warna = status.
  • Ketuk tanggal untuk melihat daftar task hari itu (di laptop tampil di sisi kanan).
  • Pilih Kanban Plan Task atau Kanban Dokumen di dropdown kanban untuk menampilkan salah satu saja, lalu saring lagi per status.
  • ‹ › pindah bulan, Hari ini kembali ke bulan berjalan.

8. Who-What

  • Daftar task per orang/PIC, diurutkan dari yang paling banyak overdue.
  • Secara bawaan hanya task aktif; centang Tampilkan semua untuk menyertakan yang sudah closed.
  • Filter kanban, status, dan prioritas juga berlaku di sini.
  • Tombol PDF di samping nama mengekspor task orang/PIC itu saja.

10. Arsip

Supaya task yang sudah selesai tidak menumpuk di papan. Arsip tidak menghapus data.

  1. Satu kartu: buka kartu yang sudah Closed / Reject / Plan Task Closed → 📦 Arsipkan.
  2. Satu kolom: tekan 📦 Arsipkan di judul kolom. Di mode Tim hanya task milik atau buatan Anda yang ikut.
  3. Melihat arsip: tekan 📦 Arsip (n) di baris filter. Tekan lagi untuk kembali ke papan.
  4. Membuka kembali: di tampilan Arsip, buka kartunya → ↩ Keluarkan dari arsip (kembali ke kolom Closed) atau Reopen (aktif lagi).

11. Offline & muat ulang

  • Tanpa sinyal, aplikasi menampilkan data terakhir dengan pita kuning OFFLINE. Data tidak bisa diubah sampai sinyal kembali.
  • Data dimuat ulang otomatis saat aplikasi dibuka kembali; tekan ⟳ untuk memuat sekarang.
  • Jika muncul “Task sudah diubah orang lain”, data dimuat ulang otomatis. Ulangi perubahan Anda.

12. Pertanyaan umum

Lupa PIN?
Minta admin mereset lewat menu Task MonitorinG → Tambah user / reset PIN di spreadsheet.
Nama saya tidak ada di daftar login?
Admin belum menambahkan Anda, atau akun Anda dinonaktifkan.
Kenapa saya tidak bisa memindahkan kartu?
Di mode Tim hanya PIC atau pembuat task yang bisa mengubah. Urutan status juga harus sesuai alur (misalnya Plan Task tidak bisa langsung Closed).
Tampilan tidak berubah setelah ada pembaruan?
Tutup aplikasi sepenuhnya lalu buka lagi sekali atau dua kali.
Muncul “Server masih versi lama” atau “Action tidak dikenal”?
Admin perlu memperbarui Code.gs di Google Apps Script dan deploy New version.
